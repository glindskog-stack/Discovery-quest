# Discovery Quest

An installable web app (PWA) for teens to explore math/science, creative
writing, coding, and trivia through an adaptive branching quiz — no
grading, no gold stars, just leveling up whatever you're curious about.

**Try it:** open this repo's GitHub Pages URL on your phone and use
"Add to Home Screen" to install it.

This is a deployment snapshot — active development happens in a private
repo and gets pushed here when there's something new to try.
